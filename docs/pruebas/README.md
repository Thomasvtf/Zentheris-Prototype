# 09 · Pruebas

| Archivo o carpeta | Qué es | ¿Cambia seguido? |
|---|---|---|
| `PLAN-DE-PRUEBAS.md` | El estándar: cómo se planea, diseña, ejecuta y registra cada prueba. Empieza aquí | Casi nunca |
| `REGISTRO-DE-PRUEBAS.md` | Todos los casos, su estado, resultados, hallazgos e historial de ejecuciones | Con cada ejecución |
| `matriz-pruebas-backend-*.md` | Detalle de los casos de las pruebas automáticas del backend (grupos P a S); copia en `docs/pruebas/` del repositorio | Solo si se agrega un caso |
| `scripts/` | Programas de apoyo para las pruebas con la base real o el servidor publicado | Cuando se agrega un caso |
| `evidencias/` | Una carpeta por caso con sus evidencias (`<ID>/<AAAA-MM-DD>_<descripcion>`) | Con cada ejecución manual |
